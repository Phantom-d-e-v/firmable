How scoring works

The input is one month-slice of Shodan internet-scan banners (14.6M services on 5.0M IPs). Each service is attributed to a company, then rolled up per company.

  • Attribution: a company is a domain named in a TLS certificate or HTTP Host header it chose. Reverse-DNS names, hosting providers (detected by co-tenancy), shared-hosting IPs, SaaS platforms and CDNs are filtered out, and so are honeypots and attacker C2 servers.
  • Need: backdoor/implant detected (+25), known-exploited CVEs from CISA KEV (+8 each, max 5), EPSS ≥ 50% (+10), exposed ICS/medical (+10), remote access/databases/app servers/edge appliances (+8), file shares and network admin (+6), cameras and printers (+3), end-of-life software (+6), TLS hygiene (up to +7).
  • Maturity: security.txt (−5) or everything behind a CDN (−5): already invested.
  • Noise control: KEV CVEs inferred on more than 20k banners (e.g. HTTP/2 Rapid Reset on every nginx) don't count.
  • Fit: vertical (rules on domain + exposed service type) and size (IPs observed).

Weights are v0 and are evaluated against hand labels (precision@k, ablation). See the repository write-up.
